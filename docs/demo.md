## About this demo

Three pages in How It Works describe the demo. [Detection](how-it-works/demo-detection.md) explains how it detects and where its limits are. [Spectrogram](how-it-works/demo-spectrogram.md) explains its two spectrograms. [Adding Models](how-it-works/demo-adding-models.md) explains how to add a model to the menu.

The sample soundscape is the example recording of [BirdNET-Analyzer](https://github.com/birdnet-team/BirdNET-Analyzer){ target="_blank" rel="noopener noreferrer" } (`birdnet_analyzer/example/soundscape.wav`, MIT License), resampled to 32 kHz. The [BirdNET website demo](https://birdnet.cornell.edu/demo/){ target="_blank" rel="noopener noreferrer" } uses the same file. Recordings loaded by their XC number come from [Xeno-canto](https://xeno-canto.org){ target="_blank" rel="noopener noreferrer" } under the license of each recording.
